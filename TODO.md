# EFFORT public centerpiece

Outcome: bring the public EFFORT experience up to the real app's working model and improve its robustness and presentation. A small classified-text demo does not satisfy this goal.

- [ ] Durable capture: per-record transactional storage, nondestructive v1 migration, quarantine and recovery without blocking new captures, drafts and verified backups.
- [ ] Real Attention Spans: named searchable directory, chronological posts, nested replies, source links, attachments/artifacts, permalinks and return paths.
- [ ] Intent and continuity: neutral states, explicit promotion, one chosen NOW, completion receipts, hold/resume and safe exploration branches.
- [ ] Meaningful depth: Proof, People, Moves and Workspace through Attention Spans, with synthetic examples and readable source-linked artifacts.
- [ ] Honest assistance: explicit invocation, bounded roles, source/provenance/permission receipts and clear configured/example/unavailable states. No private backend, hidden tools or paid provider dependency.
- [ ] Resilience: migrations, duplicate/retry handling, cross-tab consistency, quota/failure recovery, offline use and portable restore.
- [ ] Public quality: calm home, progressive disclosure, accessible phone/desktop layouts, real workflow demonstrations, source documentation and publication guard.
- [ ] Release evidence: relevant full suites, fault and concurrency acceptance, fresh-clone checks, hosted checks and private-data review.

Private Android app/data and existing personal writing remain separate. Preserve existing public visitor data when upgrading. Keep this objective intact across implementation slices; green narrow tests are not completion evidence for the whole product.
