Source and demo boundaries ↗
BROWSER ONLY

Checking storage…

Captures stay in this browser's storage. There are no accounts or trackers. Optional helper requests go only to the configured loopback companion after your explicit approval. Use fictional text. Anyone with access to this browser profile can read its demo data.

This is a browser demonstration, not the private Android app, its SQLite database, or a native phone backup.

Offline cache budget and cleanup

Open to check regenerable offline shell cache.

This never removes captures, drafts, files, history, recovery copies or backups. It removes only public app-shell cache entries that a later online reload can recreate. Offline reopening will wait for that reload.

AN EXIT DOOR

Take the original with you.

Download a checksum-checked demo backup. Restoring adds missing captures, preserves current originals and refuses conflicting records.

RECOVERY, WITHOUT ERASURE

Keep the damaged copy, too.

Download a demo backup to keep the recovery records along with your verified originals. Raw copies below are preserved as evidence, not promoted as verified text.

What is deliberately outside this demo?

Repository execution, the private backend, notifications and native phone backup/restore. Optional text-only helpers use your configured self-hosted companion; no model or companion is bundled into the hosted page. Passing the browser tests doesn't establish an installed Android build or a production service.

Why exploration works this way ↗

Classification is heuristic and can be wrong. A category is a view, not a decision about your intent.
