BROWSER ONLY

Checking storage…

Captures stay in this browser's storage. There are no accounts, trackers or provider calls. Use fictional text. Anyone with access to this browser profile can read its demo data.

This is a browser demonstration, not the private Android app, its SQLite database, or a native phone backup.

AN EXIT DOOR

Take the original with you.

Download a checksum-checked demo backup. Restoring adds missing captures, preserves current originals and refuses conflicting records.

What is deliberately outside this demo?

Voice capture, agent execution, the private backend, notifications and native phone backup/restore. Passing the browser tests doesn't establish an installed Android build or a production service.

Classification is heuristic and can be wrong. A category is a view, not a decision about your intent.
